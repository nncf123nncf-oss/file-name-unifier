# ファイル名ととのえ（file-name-unifier）

バラバラなファイル名を、自分で決めた命名ルールにそろえて、**新しい名前のコピー**を書き出すWindowsアプリです。
100日100プロダクトチャレンジ Day064。

- 元のファイルは変更しません（名前・中身・更新日はそのまま）
- アプリは通信しません。ログイン・会員登録も要りません
- 保存するのは、名前のルールの設定だけです（ファイル名やファイルの中身は保存しません）

## できること

1. **ファイルを選ぶ**（複数。上限50件・合計100MB）
2. **名前のルールを組み立てる**: `{日付}` `{取引先}` `{書類種別}` `{金額}` `{連番}` `{元の名前}` と自由な文字を並べる。区切り（`_` / `-` / なし）、日付の形（`20261009` / `2026-10-09`）、連番の桁数を選ぶ
3. **取り除く文字を登録する**: `(1)` `コピー` `- Copy` `最終版` など。元の名前・取引先・書類種別から取り除く（単語の途中でも消えます。例: `コピー用紙` → `用紙`）
4. **変更前 → 変更後を見て確認する**: 取り除かれる文字に取り消し線、同名・使えない文字・長すぎる名前・Windowsの予約名には注意の表示
5. **保存先を選んで書き出す**: 同じ名前が保存先にあるときは、上書きせず連番を付ける

例:

| 元の名前 | ルール `{日付}_{元の名前}` の結果 |
|---|---|
| `請求書 (1).pdf` | `20261010_請求書.pdf` |
| `見積書 - コピー.pdf` | `20261010_見積書.pdf` |
| `納品書_最終版.pdf` | `20261010_納品書.pdf` |
| `IMG_001.jpg`（ルール `旅行_{連番}`） | `旅行_001.jpg` |

（日付は、元の名前に日付がなければファイルの更新日です。上の例は更新日が 2026-10-10 のファイルで試した結果です）

## 使いかた

1. 配布のzipを右クリック →「すべて展開」で、**フォルダごと**展開します
2. 展開したフォルダの中の `file_name_unifier.exe` をダブルクリックします
3. `file_name_unifier.exe` に**ファイルをドロップして**起動すると、最初から選んだ状態で開きます

> **exeだけを取り出して使うことはできません。** 同じフォルダにある `flutter_windows.dll`・`file_selector_windows_plugin.dll`・`data` フォルダが必要です。別の場所で使うときは、フォルダごとコピーしてください。
>
> 署名をしていないため、初回はWindowsの警告（SmartScreen）が出ることがあります。「詳細情報」→「実行」で起動できます。

## 動作環境

- Windows 10 以上（64bit）
- Android・iPhone・Mac版はありません（Androidは後日追加の予定。iPhone版は作る予定が今はありません）

## 作っていないもの（今回）

- ドラッグ＆ドロップ（ウィンドウの中へ）での選択。exeのアイコンへのドロップによる起動は可
- 取引先・書類種別の全件への一括入力（行ごとの入力のみ）
- 書き出し結果の履歴ファイル
- ファイルの中身（PDF・画像）の読み取り・OCR・自動分類
- 元のファイルのその場でのリネーム、上書き、移動、削除
- クラウド連携、会計ソフト連携

## 既知の制約・未確認

- 元の名前の日付は、`2026-09-05`・`20260905`・`2026年9月5日`・`R8.9.5` などを読みます。型番・注文番号を日付と読む場合があるため、採用した日付を行に表示し、その行だけ「更新日を使う」に切り替えられます
- **元の名前に日付が含まれていると、日付が二重になります。** 日付の部品は先頭などに足すだけで、元の名前の中の日付は消しません（例: `最終版_納品書_2026-10-09.pdf` → `20261009_納品書_2026-10-09.pdf`）。消したい日付は「取り除く文字」に登録してください
- 金額は `¥12,000` / `12000円` のように印のあるものだけ読みます。読めないときは空欄のままにします
- 保存先がOneDriveなどの同期フォルダのとき、同期の動作によっては保存先の挙動が変わることがあります（未確認）
- 検証はWindows 11の1台で行っています。他のWindows環境、Windows 10での動作は未確認です
- 非ASCIIのパス・長いパス（260文字超）の挙動は、ごく一部しか確認していません

## 開発

Flutter 3.47.7（Dart 3.13.5）で作っています。

```
flutter pub get
flutter analyze
flutter test        # 59件
flutter build windows --release
```

ビルドの成果物は `build\windows\x64\runner\Release\` に出ます。Windowsのパスの長さ制限（260文字）のため、プロジェクトは短いパスに置いてください。

使っているパッケージ（いずれも flutter.dev 公式）: `file_selector` 1.1.0、`shared_preferences` 2.5.6。
